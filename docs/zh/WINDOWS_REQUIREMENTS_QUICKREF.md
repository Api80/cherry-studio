# Windows 系统要求快速参考

> Cherry Studio Windows 版本最低运行要求

## 🖥️ 最低配置（能用）

| 项目 | 要求 |
|-----|------|
| **操作系统** | Windows 10 (1809+) 64位 |
| **处理器** | 双核 2.0 GHz |
| **内存** | 4 GB RAM |
| **存储** | 500 MB 可用空间 |
| **显卡** | DirectX 11 支持 |
| **屏幕** | 1280 x 720 |
| **网络** | 互联网连接 |

## ⭐ 推荐配置（流畅）

| 项目 | 要求 |
|-----|------|
| **操作系统** | Windows 10 21H2+ / Windows 11 |
| **处理器** | 四核 2.5 GHz |
| **内存** | 8 GB RAM |
| **存储** | 2 GB 可用空间（SSD）|
| **显卡** | 独立显卡 |
| **屏幕** | 1920 x 1080 |
| **网络** | 宽带连接 |

## ✅ 支持的 Windows 版本

- ✅ Windows 11（所有版本）
- ✅ Windows 10 21H2 及更高
- ✅ Windows 10 2004 (20H1) 及更高
- ⚠️ Windows 10 1809 - 1903（基本支持）
- ❌ Windows 8.1 及更早（不支持）

## 📦 支持的架构

- ✅ **x64 (64位)** - Intel/AMD 处理器
- ✅ **ARM64** - ARM Windows 设备（如 Surface Pro X）
- ❌ **x86 (32位)** - 不支持

## 🚫 不支持的系统

- ❌ Windows 7 及更早
- ❌ Windows 8/8.1
- ❌ 32位系统（x86）
- ❌ Windows 10 LTSC 2015

## 💡 快速检查

### 检查你的 Windows 版本

1. 按 `Win + R`
2. 输入 `winver` 并回车
3. 查看版本号

**最低要求**: 版本 1809 (内部版本 17763) 或更高

### 检查系统架构

1. 右键点击"此电脑"
2. 选择"属性"
3. 查看"系统类型"

**必须**: 64位操作系统

### 检查内存大小

1. 打开任务管理器 (`Ctrl + Shift + Esc`)
2. 点击"性能"标签
3. 查看"内存"

**最低**: 4 GB，**推荐**: 8 GB

## ⚙️ 特殊功能要求

| 功能 | 额外要求 |
|-----|---------|
| OCR 文字识别 | Windows 10 1903+ |
| 语音输入输出 | Windows 10 2004+ |
| GPU 硬件加速 | DirectX 11/12 支持 |
| 本地 Ollama 模型 | 8GB+ 内存，NVIDIA GPU（推荐）|

## 📝 常见问题

### Q: 我的电脑能运行吗？

**检查清单**:
- ✅ Windows 10 1809 或更高？
- ✅ 64位系统？
- ✅ 4GB 内存或更多？
- ✅ 500MB 可用空间？
- ✅ 有互联网？

**全部"是"** → 可以运行！

### Q: Windows 7 能用吗？

**A**: ❌ 不能。最低需要 Windows 10 1809。

### Q: 32位系统能用吗？

**A**: ❌ 不能。只支持 64位系统。

### Q: 需要独立显卡吗？

**A**: ⚠️ 不必须，但推荐。
- 基础使用：集成显卡即可
- 流畅体验：独立显卡更好
- 本地模型：NVIDIA GPU 强烈推荐

### Q: 需要多少空间？

**A**: 
- 安装：约 500 MB
- 使用：500 MB - 5 GB（取决于数据量）
- 推荐：预留 2-5 GB
