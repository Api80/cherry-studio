## Windows 系统要求

### 最低要求 ⚠️

| 组件 | 最低配置 | 说明 |
|-----|---------|------|
| **操作系统** | Windows 10 (1809+) | 64位，版本 1809 或更高 |
| **处理器** | Intel Core i3 / AMD Ryzen 3 | 双核 2.0 GHz 或更高 |
| **内存** | 4 GB RAM | 运行基本功能 |
| **存储空间** | 500 MB 可用空间 | 安装程序和基础数据 |
| **显卡** | DirectX 11 支持 | 集成显卡即可 |
| **屏幕分辨率** | 1280 x 720 | 最低分辨率 |
| **网络** | 互联网连接 | 访问 AI 服务 |

安装时可能需要以下依赖：

```bash
# Ubuntu/Debian
sudo apt-get install libgtk-3-0 libnotify4 libnss3 libxtst6 \
  libatspi2.0-0 libsecret-1-0 libgbm1

# Fedora/RHEL
sudo dnf install gtk3 libnotify nss libXtst at-spi2-core libsecret mesa-libgbm

# Arch/Manjaro
sudo pacman -S gtk3 libnotify nss libxtst at-spi2-core libsecret
```

## 硬件要求

### CPU (处理器)

#### 最低要求 ⚠️
- **架构**: x64 (64位) 或 ARM64
- **核心数**: 双核
- **频率**: 2.0 GHz 或更高
- **代数**: 
  - Intel: Core 第 4 代 (Haswell, 2013) 或更新
  - AMD: Ryzen 1000 系列 (2017) 或更新
  - ARM: Apple M1 或更新

#### 推荐配置 ⭐
- **架构**: x64 或 ARM64
- **核心数**: 四核或更多
- **频率**: 2.5 GHz 或更高
- **代数**:
  - Intel: Core 第 8 代 (Coffee Lake, 2017) 或更新
  - AMD: Ryzen 3000 系列 (2019) 或更新
  - ARM: Apple M1/M2/M3

### 内存 (RAM)

| 使用场景 | 最低要求 | 推荐配置 | 最佳配置 |
|---------|---------|---------|---------|
| **基础对话** | 4 GB | 8 GB | 16 GB |
| **多对话** | 6 GB | 12 GB | 16 GB |
| **大型知识库** | 8 GB | 16 GB | 32 GB |
| **开发调试** | 8 GB | 16 GB | 32 GB |

### 存储空间

| 用途 | 最低空间 | 推荐空间 | 说明 |
|-----|---------|---------|------|
| **应用程序** | 200 MB | 500 MB | Cherry Studio 安装包 |
| **用户数据** | 100 MB | 500 MB | 对话历史、设置 |
| **缓存** | 100 MB | 500 MB | 临时文件、模型缓存 |
| **知识库** | 100 MB | 1 GB | 文档、向量数据库 |
| **总计** | 500 MB | 2-5 GB | 建议使用 SSD |

**存储类型**:
- ✅ **SSD（固态硬盘）**: 强烈推荐，提升启动和响应速度
- ⚠️ **HDD（机械硬盘）**: 可用，但性能较差

### 显卡 (GPU)

| 场景 | 要求 | 说明 |
|-----|------|------|
| **基础使用** | 集成显卡 | Intel HD Graphics 4000+ / AMD Radeon 等 |
| **推荐使用** | 独立显卡 | 支持 DirectX 11/12 或 OpenGL 3.3+ |
| **最佳体验** | 现代独立显卡 | NVIDIA GeForce / AMD Radeon 2GB+ 显存 |

**GPU 加速**:
- ✅ Windows: DirectX 11/12
- ✅ macOS: Metal
- ✅ Linux: OpenGL 3.3+ / Vulkan

### 显示器

| 配置 | 分辨率 | 说明 |
|-----|--------|------|
| **最低** | 1280 x 720 (HD) | 可用但布局可能拥挤 |
| **推荐** | 1920 x 1080 (Full HD) | 最佳显示效果 |
| **最佳** | 2560 x 1440 (2K) 或 3840 x 2160 (4K) | 高分辨率体验 |

**多显示器支持**: ✅ 完全支持

### 输入设备

- ✅ **鼠标/触控板**: 必需
- ✅ **键盘**: 必需
- ✅ **触摸屏**: 可选，支持触摸操作（Windows/某些 Linux）
- ✅ **麦克风**: 可选，用于语音输入

## 性能优化建议

### 提升性能

1. **使用 SSD**
   - 存储空间改为 SSD
   - 提升 50-100% 启动速度

2. **增加内存**
   - 8GB → 16GB
   - 支持更多并发对话

3. **更新系统**
   - 保持操作系统最新
   - 获得性能和安全改进

4. **关闭不必要程序**
   - 释放系统资源
   - 提升响应速度

5. **使用独立显卡**
   - 启用 GPU 加速
   - 更流畅的界面渲染

### 节省资源

1. **减少知识库大小**
   - 定期清理不用的文档
   - 使用外部存储

2. **限制缓存**
   - 设置缓存大小限制
   - 定期清理缓存

3. **减少并发对话**
   - 关闭不用的对话窗口
   - 降低内存占用

## 常见问题

### Q1: 我的电脑能运行 Cherry Studio 吗？

**A**: 检查以下条件：

✅ **可以运行**（满足以下所有条件）:
- Windows 10 1809+ / macOS 11+ / Linux (64位)
- 4GB 内存
- 500MB 可用空间
- 互联网连接

❌ **无法运行**（满足以下任一条件）:
- 32位操作系统
- Windows 8.1 或更早
- macOS 10.15 或更早
- 少于 4GB 内存

### Q2: Cherry Studio 支持 32位系统吗？

**A**: ❌ **不支持**

Cherry Studio 基于 Electron 38，仅支持 64位系统：
- x64 (64位 Intel/AMD)
- ARM64 (64位 ARM)

### Q3: Windows 7 能运行 Cherry Studio 吗？

**A**: ❌ **不能**

最低要求 Windows 10 1809。Windows 7 已停止支持。

### Q4: 为什么 Cherry Studio 需要这么多内存？

**A**: Cherry Studio 是 Electron 应用：
- Chromium 内核: 约 200-300MB
- 应用逻辑: 约 100-200MB
- 对话数据: 约 100-500MB（取决于使用）

**优化建议**:
- 关闭不用的对话
- 定期清理缓存
- 使用轻量级模型

### Q5: 我需要 GPU 吗？

**A**: ⚠️ **非必需，但推荐**

| 场景 | GPU 要求 |
|-----|---------|
| 基础对话 | ❌ 不需要 - 集成显卡即可 |
| 流畅界面 | ✅ 推荐 - 独立显卡更好 |
| 本地模型 (Ollama) | ✅✅ 强烈推荐 - NVIDIA GPU 显著提速 |

### Q6: Cherry Studio 占用多少存储空间？

**A**: 

```
安装包: 150-200 MB (Windows), 200-300 MB (macOS)
安装后: 300-500 MB
+ 用户数据: 100-500 MB
+ 缓存: 100-500 MB
+ 知识库: 取决于使用量
─────────────────────────
总计: 约 500 MB - 5 GB
```

### Q7: 可以在虚拟机中运行吗？

**A**: ✅ **可以**，但性能会下降

**建议配置**（虚拟机）:
- 分配 4 核 CPU
- 分配 8GB 内存
- 启用 3D 加速
- 使用桥接网络

**性能对比**:
- 物理机: 100% 性能
- 虚拟机: 60-80% 性能

### Q8: ARM 版 Windows 支持吗？

**A**: ✅ **完全支持**

Cherry Studio 提供 ARM64 版本：
- Surface Pro X
- 其他 ARM Windows 设备

性能与 x64 版本相当。

### Q9: 我应该选择哪个版本？

**A**: 

| 系统 | 推荐版本 | 下载 |
|-----|---------|------|
| **Windows x64** | cherry-studio-setup.exe | 通用版本 |
| **Windows ARM64** | cherry-studio-arm64-setup.exe | ARM 设备 |
| **macOS Intel** | cherry-studio-x64.dmg | Intel Mac |
| **macOS Apple Silicon** | cherry-studio-arm64.dmg | M1/M2/M3 Mac |
| **Linux x64** | .deb / .rpm / .AppImage | 根据发行版选择 |

### Q10: 系统要求会变化吗？

**A**: ⚠️ **可能会**

随着 Electron 和功能更新：
- 最低 Windows 版本可能提升到 Windows 10 2004
- 内存要求可能增加到 6GB
- 存储空间可能增加

**建议**: 使用推荐配置而非最低配置。
